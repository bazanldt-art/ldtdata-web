Lo que encontré

  1. La mora se dispara en el segundo semestre de 2025: las cuotas con atraso pasan de un 15 % estable a 25 % en el T3 y a 41 % en el T4.
  2. Vuelven los atrasos de 45 días, ausentes entre 2022 y 2024: las cuotas vencidas suben de 2 % a 32 % en el T4.
  3. Aun así, la recuperación se mantiene en ~95 % (96,5 % en el T4): los clientes pagan, pero tarde. Es un problema de oportunidad de cobro, no de pérdida, y afecta por igual a todas las sedes, segmentos y ejecutivos (95,0 %–95,7 %).

SELECT
    CONCAT(YEAR(d.FechaProgramadaPago), '-T', DATEPART(QUARTER, d.FechaProgramadaPago)) AS Trimestre,
    COUNT(*) AS Cuotas,
    AVG(CASE WHEN d.FechaPago IS NOT NULL AND d.DiasMora = 7  THEN 1.0 ELSE 0 END) AS PctAtraso7,
    AVG(CASE WHEN d.FechaPago IS NOT NULL AND d.DiasMora = 18 THEN 1.0 ELSE 0 END) AS PctAtraso18,
    AVG(CASE WHEN d.FechaPago IS NULL OR d.DiasMora = 45     THEN 1.0 ELSE 0 END) AS PctAtraso45OSinPago,
    SUM(d.MontoPagado) / SUM(d.MontoProgramado) AS Recuperacion
FROM DetallePagosCredito d
WHERE d.FechaProgramadaPago < '2026-01-01'
GROUP BY YEAR(d.FechaProgramadaPago), DATEPART(QUARTER, d.FechaProgramadaPago)
ORDER BY YEAR(d.FechaProgramadaPago), DATEPART(QUARTER, d.FechaProgramadaPago);

Fuente: base académica BD_FinanzasCobranza (1.500 créditos, 4 sedes, 12 clientes ficticios), replicada y publicada solo como totales agregados.

La base registra las 6 primeras cuotas de cada crédito; el saldo pendiente se calcula sobre esas cuotas. Se excluyen las cuotas con vencimiento en 2026, fuera del periodo de estudio.
